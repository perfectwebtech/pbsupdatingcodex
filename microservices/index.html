🚀 Quick Start

# Start all services
docker-compose up -d

# View logs
docker-compose logs -f

# Test services
./test-services.sh

# Stop services
docker-compose down

📡 API Endpoints

  • Authentication: http://localhost:8080/api/v1/auth/*
  • Streaming: http://localhost:8000/api/v1/streams/*
  • Transcoding: http://localhost:8002/api/v1/transcode
  • Recommendations: http://localhost:8003/api/v1/recommendations/*
  • WebSocket: ws://localhost:8001/ws
